# /handoff — End-of-Session State Save

Save the current session state so the next session can pick up where this one left off.

## Steps

1. Summarize what was accomplished this session.
2. List any in-progress or unfinished work.
3. Note any blockers or open questions.
4. Write the summary to `.scratchpad/status.md` with the current date.
5. Update `.scratchpad/blockers.md` if there are active blockers.
6. Log any significant decisions made to `.scratchpad/decisions.md`.
